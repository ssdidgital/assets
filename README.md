# System Switch brand

- `System Switch Brand Book.html`: 46-slide brand book, self-contained (open in any browser; print to PDF from the browser).
- `brand-kit/Brand Kit.html`: sizes and usage for every profile, cover and email asset.
- `brand-kit/png/`: avatars (400), app icon (1024), LinkedIn banner (1584×396), LinkedIn company cover (1128×191), Facebook cover (851×315), email mark (144).
- `brand-kit/pattern/`: six seamless SVG pattern tiles.
- `brand-kit/Email Signature.html`: signature preview, HTML and install steps. Upload `png/email-mark-144.png` and replace `YOUR-SITE` in the HTML.
